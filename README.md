# Painel SARESP — PEI Marisa de Mello

Painel web responsivo para acompanhamento pedagógico dos resultados do 5º ano, com histórico por bimestre, filtros, plano de intervenção e banco de aulas e questões.

## Arquivo principal

O painel completo está em [index.html](./index.html).

## Habilitar o site pelo GitHub Pages

1. Abra **Settings** deste repositório.
2. Acesse **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
5. Após a publicação, o endereço geralmente será `https://camposivan.github.io/portal-marisa/`.

O painel carrega bibliotecas de interface por CDN e utiliza links externos para os materiais e as questões.
